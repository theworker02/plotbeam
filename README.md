# plotbeam

Plot lightweight beam statistics from stdin samples.

**Site:** https://theworker02.github.io/plotbeam/

## Install / run

```bash
git clone https://github.com/theworker02/plotbeam.git
cd plotbeam
node src/cli.js
node --test
```
